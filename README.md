# Stable Diffusion 提示词创作与优化助手

AI 产品设计与策划 · 独立项目（2025.01–2026.05）

本仓库是 **Stable Diffusion 提示词创作与优化助手** 的独立作品集网站。网页展示用户需求、四大功能模块、自然语言生成、提示词优化、参考图反推、Newbie 专项适配、XML 结构化 Prompt 规则及产品交付方式。

**在线展示：** https://hajimi-tomato.github.io/sd-prompt-studio/

## 网站内容

- 项目背景与用户洞察
- 四份项目文档对应的功能矩阵
- 四类主要用户交互路径
- Prompt 分类体系与 XML 输出机制
- Discord 社群 Bot 与本地客户端使用路径
- 真实累计使用数据（统计截至 2026 年 5 月）

## GitHub Pages

本仓库使用纯静态 HTML / SVG 文件，无需构建依赖。

首次部署时，在仓库 `Settings → Pages → Build and deployment` 中将 `Source` 设为 **Deploy from a branch**，`Branch` 选择 **main / (root)**，保存即可。此后提交到 main 分支会自动发布。

## 内容边界

网页根据项目功能文档整理。示例为展示性流程，不是接入实时模型的聊天界面；出于隐私与配置安全考虑，不公开完整 Prompt 文件、API 密钥或私人联系方式。
